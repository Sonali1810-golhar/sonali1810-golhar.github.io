# Sonali Golhar — Data Engineer Portfolio

A responsive, static portfolio built with **HTML + CSS + vanilla JavaScript**. It has no build step and can be uploaded directly to GitHub and deployed with GitHub Pages.

## Folder structure

```text
sonali-data-engineer-portfolio/
├── index.html
├── styles.css
├── script.js
├── README.md
├── TESTING.md
└── assets/
    ├── favicon.svg
    ├── sonali-profile.jpg
    └── Sonali_Golhar_Resume.pdf
```

## Run locally

### Option 1 — VS Code
Open the folder and use any local static server extension, then open `index.html`.

### Option 2 — Python
From this folder:

```bash
python -m http.server 8000
```

Open `http://localhost:8000`.

### Option 3 — Direct
Double-click `index.html`. Most sections work directly from the file system; a local server is recommended for the closest deployment test.

## GitHub upload

1. Create a new GitHub repository.
2. Upload **all files and folders inside this folder**.
3. Make sure `index.html` is at the repository root.
4. In GitHub: **Settings → Pages → Deploy from a branch → main → /(root)**.
5. Save and open the generated Pages URL.

## Before publishing

- Replace project-level `GitHub Repository` placeholders with the real repository URLs when available.
- The resume, email, GitHub and LinkedIn details are populated from the supplied resume.
- Do not add claims, metrics, companies, certifications, or links that are not verified.
